# Guild Hall trust graph: SVG spec

The SVG trust graph on the agent page (`:agent/<addr>`, PRD §9.4, FR-12). Designed by Dilly, implemented by Ancung in `sc/r/hireling/render.gno` with `gno.land/p/nt/svg/v0`.

Samples that follow this spec: `guild-hall-sample.svg` (12 backers shown plus a "more" node), `guild-hall-sample-empty.svg`, `guild-hall-sample-banned.svg`. They are generated by `scripts-design/guild-hall-samples.mjs` (`node design/scripts-design/guild-hall-samples.mjs`), which is the reference for the layout maths below.

## 1. What `p/nt/svg/v0` can do on Onyx

Checked on 2026-11-26 by reading `gno.land/p/nt/svg/v0/svg.gno` from the Onyx RPC (`vm/qfile`).

- Elements: `circle`, `ellipse`, `rect` (with `rx`, `ry`), `path`, `polygon`, `polyline`, `text`, `g`.
- Attributes on every element (`BaseAttrs`): `id`, `class`, `style` (raw string), `stroke`, `stroke-width`, `opacity`, `transform`, `visibility`.
- Canvas: `width`, `height`, `viewBox`, and a `<style>` block built from `AddStyle(selector, rules)`.
- All coordinates and sizes are **integers** (`%d`).
- No `defs`, gradients, filters, masks or clip paths. Glass, blur and glow from the web design are approximated with solid shapes and opacity.
- `Text` content is written **unescaped**. No user-supplied text (names, descriptions, tags) ever goes into the SVG. Only numbers and addresses shortened by the realm.
- `Canvas.Render(alt)` returns `![alt](data:image/svg+xml;base64,...)`. gnoweb shows it as an image, so the SVG cannot load fonts or link anywhere.

## 2. Canvas

- `NewCanvas(640, 400).WithViewBox(0, 0, 640, 400)`. Scales to the page width.
- Background: `rect` 0,0,640,400, `rx` 24, fill `#03050F`. The SVG brings its own background, so it reads the same on gnoweb light and dark.
- Fluted texture: 32 `rect`s, each 20 wide and 400 high, at x = 20·i. Even ones fill `#FFFFFF` opacity `0.03`, odd ones opacity `0.06`.
- Glow behind the agent: 4 concentric `circle`s at the agent centre, r = 150, 115, 85, 60, fill `#1660FF`, opacity `0.06`, `0.08`, `0.10`, `0.14`.
- Text style, once, on the canvas: `AddStyle(".a", "font:500 11px ui-monospace,SFMono-Regular,Menlo,monospace")`, `AddStyle(".s", "font:700 26px system-ui,-apple-system,Segoe UI,sans-serif")`, `AddStyle(".l", "font:500 10px system-ui,-apple-system,Segoe UI,sans-serif;letter-spacing:0")`. System fonts only.

## 3. Layout

- Agent node at (320, 200).
- Backers sit on an ellipse around it: rx 230, ry 135. The owner's self-stake is always the first node, at 12 o'clock (angle −90°). The other backers follow clockwise, sorted by stake, largest first, evenly spaced: angle_k = −90° + 360°·k / n, with n = number of nodes shown.
- **At most 12 nodes.** The owner plus up to 11 backers. If there are more backers, node 12 is a "more" node showing `+N` (N backers not shown). Voucher count is unlimited (PRD §5), so the SVG stays bounded.
- Positions are rounded to integers after the trigonometry. Gno has no `math.Sin` on chain in this package; the realm can use a precomputed table of (cos, sin) × 1000 for n = 1…12, given in `guild-hall-samples.mjs` as `ANGLES`.

## 4. Nodes

| Node | Shape | Fill | Stroke |
|---|---|---|---|
| Agent | `circle` r 46 | `#2233D9` | `#8FA2FF`, width 2 |
| Agent score | `text` centred at (320, 209), class `s` | `#FFFFFF` | |
| Agent label | `text` "trust score" at (320, 226), class `l` | `#C9D4F2` | |
| Owner | `circle` r from stake (below) | `#FFFFFF` | none |
| Backer, active | `circle` | `#8FA2FF` | none |
| Backer, warm-up | `circle` | `#03050F` | `#8FA2FF`, width 2 |
| Backer, unbonding | `circle`, opacity `0.4` | `#8FA2FF` | none |
| More | `circle` r 16 | `#1B2470` | `#8FA2FF`, width 1; `text` `+N` centred, class `a`, fill `#FFFFFF` |

- Node radius: r = 8 + floor(14 · √(stake / maxStake)), so 8 to 22. `maxStake` is the largest stake among the nodes shown. In integer maths: `8 + 14 * ISqrt(stake * 10000 / maxStake) / 100`, with `ISqrt` from `p/<ns>/hireling`.
- Address label under each node: `text` at (x, y + r + 14), class `a`, fill `#C9D4F2`, the shortened address `g1` + 4 … last 4 (`g1jg8m…sqf5`). Text anchor: add `AddStyle("text", "text-anchor:middle")` once.

## 5. Edges

- One `path` per node: `M{ax} {ay} L{bx} {by}` from the agent centre to the node centre, drawn **before** the nodes so nodes sit on top.
- Width: 1 + floor(5 · √(stake / maxStake)), so 1 to 6. Same integer trick as the radius; integer division floors.
- Active and owner: stroke `#8FA2FF`, opacity `0.7`.
- Warm-up: same, plus `style="stroke-dasharray:6 6"`.
- Unbonding: opacity `0.25`.
- More node: one edge to it, stroke `#8FA2FF`, width 1, opacity `0.4`.

## 6. States

- **Empty** (owner only, no backers): owner node and agent node only, plus `text` "No backers yet" at (320, 330), class `l`, fill `#C9D4F2`.
- **Inactive** (self-stake below minimum): agent fill `#3A3F55`, stroke `#9CA5D6`; score shows `0`.
- **Banned**: agent fill `#3A3F55`, stroke `#FF7A7A` width 3, score `0`; under the label, one small `circle` r 4 fill `#FF7A7A` per strike, 12 apart, centred at y 244. All edges at opacity `0.25`.

## 7. Size and alt text

- Budget: **≤ 8 KB** of SVG for the 12-node case (base64 adds about a third). The samples are measured in the PR.
- Alt text (the Markdown image alt): "Trust graph of g1jg8m…sqf5, score 240, 2 backers, 400 GNOT at stake". Built only from numbers and the shortened address. No `·`, no user text.
